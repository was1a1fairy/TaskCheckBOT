# TaskCheckBOT 🤖

Телеграм-бот для управления личными задачами.

## Что умеет

- ➕ Добавлять задачи с дедлайнами, приоритетами и описаниями
- 📋 Просматривать список задач с разными сортировками
- ✏️ Редактировать задачи
- ✅ Отмечать выполненные
- 🗑️ Удалять ненужное
- ⏰ Напоминать о дедлайнах
- 📊 Показывать аналитику (процент выполнения, распределение по приоритетам)


## Стек

- aiogram — телеграм-бот
- aiosqlite — база данных
- apscheduler — напоминания
- numpy — аналитика

## Команды

- `/start` — начать
- `/exit` — в главное меню
- Кнопки в меню — всё остальное
